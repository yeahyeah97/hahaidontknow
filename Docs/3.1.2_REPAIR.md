# Milazy 3.1.2 latency and correction repair

Reported cases: osa, far, vediam. Expected Italian reconstruction:
cosa, fare, vediamo. Far is valid English and an Italian shortened infinitive:
expanding it depends on forced Italian or evidence from the preceding Italian word.

Problems in 3.1.1:
- Each key read the host text context and document identifier repeatedly.
- All letter labels and the suggestion row were updated even when case stayed unchanged.
- Personal learning rebuilt fuzzy signatures after every word.
- Short/capitalized words were often excluded from correction.
- A word entered twice became protected even when neither occurrence was confirmed.
- The fallback corpus was a few hundred hand-written words.
- Controls rejected points outside visible bounds despite the canvas expanding hitboxes.

Repair:
- Keep a rolling input context; reconcile delayed echoes and external document/cursor changes.
- Character insertion uses cached context. Host context is read during host changes or bulk edits.
- Update rendered capitalization only when case changes. Coalesce feedback; cache preferences.
- Share one immutable frequency corpus/index, built off the main thread.
- Bundle 8,000 IT and 8,000 EN frequency entries with source attribution/license notices.
- Rank neighboring candidates by frequency and context, including short/initial-capital words.
- Automatic commits update frequency/bigrams; only selected or undone words gain protection.
- Cancel stale prediction work between expensive stages and cache spellcheck results.
- Use UIControl tracking methods and accept the invisible gap targets.

Validation:
- Portable regression checks load the complete shipped corpus, exercise the reported examples,
  repeated typo/explicit keep behavior, capitalization and delayed host echoes.
- iOS Simulator integration tests drive actual controller touchDown actions through a local
  proxy, without waiting for predictions. They assert the full "Cosa fare vediamo " result,
  first-word correction, correction undo and zero context/identifier reads per character.
- Existing Actions builds and validates an unsigned device IPA; packaging checks vocabulary files.

The simulator/local proxy verifies controller behavior and avoids network calls. It cannot
measure real host-process round trips on an iPhone or establish WhatsApp/iOS 27 latency.
Device testing remains necessary. An old learned frequency history is retained; automatic
frequencies no longer make its typos immune. New confirmed vocabulary is stored separately.
